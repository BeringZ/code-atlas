# Code Atlas 2.0

以**知识点主干 + 多语言表示 + 语言独立进阶目录**为核心的多语言编程知识体系。

> 依据《Code Atlas 2.0 产品策划与内容架构执行文档 V1.0》重构（2026-08-03）。
> 核心转变：从「以功能实现为主线」升级为「以语言无关的知识点为主干，在知识点页面切换不同语言表达」；语言特有的机制进入各语言独立进阶目录。

## 信息架构

```text
学习地图 (index.html)        基础主干 · 语言分支 · 推荐路径 · 个人进度
基础模块 (modules.html)      18 个语言无关模块 B00–B17
知识点详情 (concept.html)    共享概念 + 语言切换 + 差异解释 + 错误案例 + 练习 + 深入机制
语言进阶 (language.html)     6 语言 × 10 个机制专题（独立进阶目录）
功能实验室 (lab.html)        6 个综合任务：需求拆解 + 知识点连接 + 跨语言对照
语言百科 (encyclopedia.html) 语言定位 / 范式 / 工具链 / 生态 / 环境搭建
搜索                          全站统一索引（概念 / 模块 / 错误 / 专题）
```

## 扩展指南

- **新增语言**：在 `concept-data.js` 的 `languages` 增加元数据，为知识点补充 `variants[langId]`，新增语言进阶专题——基础导航代码无需改动（文档「新增语言低成本」原则）。
- **新增知识点**：在 `concept-data.js` 的 `concepts` 增加对象，加入模块的 `concepts` 列表；发布前需提供目标/概念/变体/练习。
- **新增专题**：在 `advanced-data.js` 的 `topics` 增加对象（含 `detail` 即精讲）。

## 设计原则（源自文档）

- 概念先于语法：先回答「这个知识解决什么问题」，再展示语言写法
- 差异必须可解释：语法 / 语义 / 惯用写法 / 常见陷阱四类说明
- 知识点原子化：一个页面一个可命名、可建立前置、可设置练习目标的知识点
- 渐进展开：初学层简明，深入机制默认折叠
- 语言特性不被平均化：语言独有内容拥有独立进阶空间
